INDI — Curaduría fotográfica
Esta web se hizo para revisar el material fotográfico de INDI y decidir qué imágenes incorporar al archivo. Reúne fotografías que ya estaban en el proyecto con material de dos ediciones recientes de BAFWEEK.
La curaduría se hace desde una galería: se pueden filtrar las imágenes, verlas en detalle y marcar las que se quieren conservar. Al terminar, se exporta un CSV con las decisiones. Otra persona puede importar ese archivo y continuar la revisión.
Es un proyecto independiente del sitio de INDI en WordPress. No utiliza servidor ni base de datos.
